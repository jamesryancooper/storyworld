# Narrative Building Blocks

Companion to `narrative-taxonomy.md`. Where the taxonomy classifies *what a work is* (family, medium, format, length, style, release model), this document catalogs the reusable creative mechanisms that generate the work itself: story engines, narrative structures, emotional arcs, and knowledge-framing patterns. All four are medium-neutral — the same engine can drive a micro video, a carousel, a podcast episode, or a novel chapter. The taxonomy's composition formula references these blocks by name.

## 1. Repeatable Story Engines

Reusable mechanisms that generate individual episodes across genres.

### Discovery Engines

* **Question → investigation → answer**
* **Search → clues → reveal**
* **Mystery object → testing → identification**
* **Hidden place → entry → discovery**
* **Familiar subject → secret meaning**
* **Evidence → competing theories → conclusion**

### Goal Engines

* **Mission → obstacles → completion**
* **Rescue → setbacks → recovery**
* **Escape → failed attempts → breakthrough**
* **Journey → trials → destination**
* **Build → failure → redesign → success**
* **Transformation → adjustment → new identity**

### Competition Engines

* **Rules → rounds → elimination → winner**
* **Two sides → escalating tests → final comparison**
* **Last participant remaining**
* **Timed challenge**
* **Points, levels, or achievement ladder**
* **Expert-versus-novice**
* **Young-versus-old**
* **Cheap-versus-expensive**

### Escalation Engines

* **Small → medium → enormous**
* **Easy → difficult → nearly impossible**
* **Safe → risky → extreme**
* **Ordinary → rare → unbelievable**
* **One → ten → one hundred**
* **$1 → $1,000 → $1,000,000**
* **Hour → day → week → month**

### Social Engines

* **Secret → suspicion → discovery**
* **Rule-breaking → consequence → lesson**
* **Conflict → separation → reconciliation**
* **Surprise preparation → reveal → reaction**
* **Rivalry → forced cooperation → mutual respect**
* **Fear → attempt → courage**
* **Wish → obstacle → fulfillment**

### Experiential Engines

* **First time doing X**
* **Living under a strange rule**
* **Spending a fixed period somewhere**
* **Trying every version of something**
* **Visiting multiple levels or locations**
* **Recreating fiction in real life**
* **Letting another person control the day**
* **Documenting a major life milestone**

### Interpretive Engines

* **What everyone thinks → why it is incomplete → deeper truth**
* **Surface plot → symbolic pattern → existential meaning**
* **Historical fact → overlooked cause → modern consequence**
* **Moral dilemma → competing principles → unresolved tension**
* **Common belief → counterexample → revised model**

## 2. Common Narrative Structures

### Classical Dramatic Structure

Hook → premise → stakes → escalating obstacles → reversal → climax → resolution → payoff.

### Explanatory Revelation Structure

Provocative question → familiar explanation → contradiction → deeper mechanism → consequences → final reframe.

### Recognition-to-Hope Structure

Recognition → naming the problem → deeper truth → cost or stakes → turning point → responsibility → practice → hope → closing truth.

### Mission Structure

Assignment → preparation → departure → complications → apparent failure → breakthrough → completion → return.

### Challenge Structure

Rules → contestants → early rounds → escalating difficulty → eliminations or setbacks → final test → winner → reward.

### Moral-Lesson Structure

Temptation or mistake → immediate benefit → worsening consequences → recognition → corrective choice → restored harmony.

### Mystery Structure

Anomaly → clues → false explanation → new evidence → revelation → reinterpretation of earlier events.

### Transformation Structure

Before state → desire → intervention → resistance → transformation → test of the new state → after state.

### Vlog-as-Story Structure

Daily premise → anticipation → experiences and interruptions → emotional peak → reflection → memory or family payoff.

### Compilation Structure

Shared theme → modular mini-stories → rising novelty → strongest segment → recap or closing lesson.

### Atmospheric Archive Structure

Fragment → recurring symbol → spatial or temporal echo → growing unease → partial revelation → unresolved residue.

## 3. Recurring Emotional Arcs

* Curiosity → wonder → understanding
* Familiarity → doubt → revelation
* Safety → disruption → restoration
* Fear → courage → mastery
* Rivalry → cooperation → belonging
* Mistake → consequence → growth
* Desire → temptation → responsibility
* Hope → setback → perseverance → triumph
* Nostalgia → unease → grief → revelation

* Chaos → problem-solving → relief
* Suspicion → discovery → trust or betrayal
* Ambition → failure → adaptation → success
* Loss → remembrance → meaning
* Surprise → delight → gratitude

## 4. Knowledge-Framing Patterns

These determine how factual or conceptual material becomes narrative.

* **Chronological:** what happened next.
* **Causal:** why it happened.
* **Systemic:** how the parts interact.
* **Biographical:** how one person shaped events.
* **Geographic:** how place determines outcomes.
* **Comparative:** how two or more cases differ.
* **Counterfactual:** what might have happened otherwise.
* **Diagnostic:** what appears wrong and what actually causes it.
* **Investigative:** what the available evidence supports.
* **Revisionist:** what conventional accounts overlook.
* **Symbolic:** what events or objects represent.
* **Experiential:** teaching through a host's attempt or journey.
* **Story-first:** a human incident introduces the larger concept.
* **Zoom structure:** individual → community → system → world.
* **Evidence-and-correction:** claim → evidence → revision, correction, or retraction.

## Using the blocks

A work selects one primary engine, one structure, one or two emotional arcs, and (for factual material) a knowledge frame; the taxonomy's remaining dimensions — medium, format and length class, realization style, presentation mode, release model, audience role, continuity model — determine how that selection is realized. In Storyworld, engines and structures become template vocabularies that validators can check (a Mystery Structure template expects an anomaly before a revelation; a Moral-Lesson template expects a corrective choice), rather than free-text genre labels.
