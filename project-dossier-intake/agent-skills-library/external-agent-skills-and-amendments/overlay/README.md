# Proposal-Only Overlay

This directory contains proposed new skill packages and reference amendments. It is intentionally **not** an installer and must not be copied into Storyworld without governed review.

- `new-skills/` contains three complete unadopted skill packages.
- `amendments/` contains reference proposals for existing Storyworld skills.
- Every new capability record keeps `permission_grant: false` and `adoption_status: generated_unadopted_baseline`.
- External sources are pinned and remain nonauthoritative evidence.
