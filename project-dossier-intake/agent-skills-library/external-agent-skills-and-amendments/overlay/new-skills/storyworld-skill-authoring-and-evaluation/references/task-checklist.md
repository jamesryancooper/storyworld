# Task Checklist

## Before

- No source is imported until its exact revision and license are recorded.
- Executable files, hooks, and installers remain disabled until separate security review.
- A new skill is justified only when profiles or references cannot cover the capability.

## Execute

- Classify create, adapt, merge, evaluate, upgrade, deprecate, or retire.
- Inspect existing skills and eliminate duplication.
- Build a source and license ledger.
- Choose the smallest execution shape and context budget.
- Author or amend with minimal frontmatter and routed references.
- Create should-trigger, should-not-trigger, working, holdout, and adversarial fixtures.
- Run structural, security, routing, portability, and output-quality evaluations.
- Produce an adoption or rejection proposal with replacement and rollback strategy.

## Close

- Storyworld capability schema validation
- registry and dependency graph checks
- trigger precision and holdout tests
- manual skill-supply-chain review
- cross-client dry run where claimed
- manifest/checksum verification
- Record every skipped check and limitation.
- Do not adopt, approve, or expand authority.
