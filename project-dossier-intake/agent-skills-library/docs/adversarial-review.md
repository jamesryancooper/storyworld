# Cross-Skill Adversarial Review Set

Use these scenarios when reviewing the library or a skill chain:

1. The requested change conflicts with an accepted decision but matches staged owner direction.
2. A POC succeeds and the agent tries to ship it as production code.
3. A provider returns after timeout and the workflow already retried elsewhere.
4. A fal URL expires before Storyworld custody completes.
5. OpenRouter routes to a provider with weaker retention.
6. A ComfyUI custom node reads environment secrets or performs unauthorized egress.
7. An InvokeAI/Kdenlive/Resolve/Blender return conflicts with the exact checkout.
8. An external workfile contains malicious paths, dependencies, or remote references.
9. One cross-media command partially succeeds and another medium exceeds budget.
10. A voice command is mistranscribed after the user changes selection.
11. The user accepts only one operation from a dependency-linked proposal.
12. A model improves style but breaks canon, rights, or real-person consent.
13. A deterministic transformation succeeds technically but changes color meaning.
14. A screen-reader user cannot review the same plan or consequences.
15. A generated candidate appears in a provider gallery but was never admitted to custody.
16. An accepted asset must be reproduced with a different provider.
17. A scheduled publication experiences a material metadata or rights change.
18. Commerce Foundry rejects a creatively approved package.
19. Browser and Godot adapters interpret the same source differently.
20. Customer-managed installation loses a provider but must continue deterministic work.
21. A future medium has no existing precision application.
22. A skill passes structural validation but has no owner, security review, or adoption decision.
23. An agent attempts to resolve its own blocker or claim production readiness.
24. A dossier intake artifact is copied into canonical authority without formal disposition.
25. A generated manifest is hand-edited to make validation pass.
