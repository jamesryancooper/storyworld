# Blender Precision Integration Profile

**Parent skill:** `storyworld-external-editor-connector`  
**Status:** implementation guidance; noncanonical and unadopted

## Purpose

Use Blender as an exceptional precision environment for 3D assets, spatial realization, cameras, lighting, animation, compositing, rendering, and runtime preparation.

## Checkout package

Include exact canonical entity/location/object refs, accepted appearance and production-design specifications, OpenUSD/MaterialX/glTF profiles where applicable, reference images, textures, fonts, color config, target cameras, runtime constraints, rights, and an integrity-protected sidecar.

## Return package

Accept .blend as a nonauthoritative workfile plus portable exports, dependency manifest, render outputs, camera/light metadata, external-file inventory, transformation declaration, and application/add-on versions. Reject or quarantine missing, absolute, remote, or unresolved dependencies.

## Authority and continuity

Blender may realize geometry, layout, materials, animation, lighting, and renders. It does not define canon, accepted appearance, production-design approval, master status, runtime acceptance, or publication. Returned renders and exports become candidates and invalidate affected evaluations.

## Adversarial cases

Missing textures, linked libraries outside package, executable scripts/add-ons, unsupported USD semantics, camera units mismatch, color-config drift, two conflicting returns, and Blender becoming unavailable.

## Permanent Storyworld boundary

- Storyworld owns creative meaning, stable IDs, exact versions, policy, custody, evaluation, human decisions, packages, and receipts.
- The external provider/tool/standard owns only bounded execution or interchange mechanics.
- Recheck current official documentation, exact version, license, security, retention, and compatibility before implementation.
- This profile grants no credentials, network calls, spending, installation, deployment, publication, or dependency adoption.
