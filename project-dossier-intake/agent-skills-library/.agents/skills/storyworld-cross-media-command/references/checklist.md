# Storyworld Cross Media Command Checklist

## Intake

- [ ] Exact request and expected side effects are stated.
- [ ] Repository revision, branch, and dirty state are known.
- [ ] Applicable `AGENTS.md` and `.agent/` governance were read.
- [ ] Relevant accepted and staged decisions were classified separately.
- [ ] A task record exists for significant work.
- [ ] External crossings, credentials, spending, publication, or deployment are explicitly gated.

## Scope and authority

- [ ] The skill is applicable and the task is not better routed elsewhere.
- [ ] Required inputs are available:
  - [ ] `CreativePlan_contract`
  - [ ] `media_operation_contracts`
  - [ ] `accepted_creative_specifications`
  - [ ] `base_versions`
- [ ] Durable semantic changes have decision-impact analysis.
- [ ] Provider/editor/runtime private formats remain behind Storyworld-owned boundaries.
- [ ] No skill, plan, fixture, or passing test is treated as permission.

## Implementation or assessment

- [ ] Resolve the command's scope, narrative intent, and affected media
- [ ] Ask or infer whether departments reinforce, contrast, withhold, destabilize, evolve, or remain ambiguous
- [ ] Create one typed operation set per medium
- [ ] Declare inter-operation dependencies and independent costs/evaluations
- [ ] Preview coordinated results while retaining per-medium before/after views
- [ ] Allow partial acceptance only when dependencies remain valid
- [ ] Create separate revisions and one coordinating decision receipt

## Invariants

- [ ] Verified: No universal mood operation
- [ ] Verified: Each medium retains its own authority and lifecycle
- [ ] Verified: Counterpoint is a first-class authored relation
- [ ] Verified: A failed operation cannot leave hidden partial cross-media application

## Validation

- [ ] Cold-scene fixture across image/video/sound/graphics
- [ ] Counterpoint fixture
- [ ] One medium fails or exceeds budget
- [ ] Partial acceptance and rollback

## Closure

- [ ] Required outputs exist:
  - [ ] `cross_media_plan`
  - [ ] `media_specific_operations`
  - [ ] `coordination_graph`
  - [ ] `coordinated_preview`
  - [ ] `partial_acceptance_constraints`
  - [ ] `decision_receipt`
- [ ] Actual commands/results and skipped checks are recorded.
- [ ] Findings name evidence, impact, remedy, and disposition owner.
- [ ] No generated file was hand-edited.
- [ ] Dirty state and unrelated changes are disclosed.
- [ ] External effects and costs are listed, including “none.”
- [ ] The result does not overclaim acceptance, readiness, or external success.
