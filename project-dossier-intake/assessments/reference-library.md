# Reference Library

The distilled conclusions of the book-research program (`../evidence/book-research/`, three research conversations): which books ground Storyworld's foundations, what each informs, when to read them relative to the decision program, and what remains unacquired. The physical library lives at `../books/` — **local-only and git-ignored** (large copyrighted files; several exceed hosting limits). All titles are **S1R-class reference material** per the ingestion plan: ideas, vocabulary, and methods only — never reusable prose, never automatic authority.

## From books to decisions: the research-package method

Books do not enter Storyworld as authority. Each relevant book converts into a small governed research package: a vocabulary crosswalk, a conflict report against the current dossier, a core-versus-template disposition, new counterexample fixtures, proposed amendments, explicit non-adoptions, and decision evidence — filed as S1R research per the ingestion plan. Living sources (platform policies, regulations, codecs, provider terms) stay in `research/` mutable-external-fact records; books establish concepts and methods, not current obligations.
