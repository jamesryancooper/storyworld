Node 22, TypeScript, pnpm, Next.js/React, project-owned vendored design system, PostgreSQL/RLS, direct `pg`, S3-compatible object storage, Temporal, JSON Schema/OpenAPI/AsyncAPI/CloudEvents, Ed25519 portability, current provider/evaluation/integration packages.

- ProseMirror vs Lexical; Tiptap as an optional acceleration layer

Yjs/CRDT collaboration, pgvector, dedicated search, dense WebGL graph, MapLibre, CEL, broad offline editing, direct publishing, advanced media authoring.
