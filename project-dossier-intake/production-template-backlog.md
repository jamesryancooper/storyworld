# Production Template Backlog

The canonical dossier's template system (chapter 02, section 7) configures vocabulary, hierarchy labels, required fields, rules, rubrics, and exports per project type without forking storage — and already defines instances derived from the original property set (editorial carousel, illustrated life manual, collectible character cards, recurring short-form comedy, branded narrative campaign, interactive memory world). The project catalog now contains many types with no template instance. This backlog enumerates the missing instances so template work can be scheduled deliberately. Target canonical home: chapter 02, section 7.

Each instance must obey the existing decision rule: configure vocabulary and validation, never new storage; a new generic primitive only when two materially different types need the same semantic.

| Template instance | Derived from | Key configuration the template must carry |
|---|---|---|
| Illustrated storybook / picture book | Ryan and Nicol; Tales from Two Kingdoms | Page/spread structure and counts; per-page text + illustration brief pairing; character-sheet binding for design continuity; bilingual transcreation pairing and accessibility renditions; print-edition fields |
| Iconographic artwork series | Saint Michael series | Canonical scene specification; style-treatment variants bound to art-style definitions; print/poster targets |
| Curriculum unit | SciSpark | 5E stage structure; learning objectives and prerequisites; assessments with instructor-only answer fields; age/reading-level variants; learner-privacy defaults; writing-style guide binding |
| Ambient scene collection | Ambience channel | Scene specification vocabulary; loop-safety validators (no motion/narrative elements); soundscape pairing; long-play packaging |
| Evidence-based documentary article | Matters of Record | Claim records with evidence links and confidence levels; conflicting-source surfacing; quote/excerpt permissions; correction/clarification/retraction actions with version preservation |

Scheduling guidance: template instances land with their property's first production (the ingestion order in `source-material-ingestion-plan.md` implies the template order — storybook first, then artwork series, curriculum, cards/ambience, advice cards, and onward). Templates for generated-concept properties wait until their concepts are adopted and named.
