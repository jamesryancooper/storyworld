## Status vocabulary

- **Accepted authority** — controlling until formally superseded.
- **Current alpha fact** — source/tests show behavior exists; not automatically target architecture.
- **Staged proposal** — dossier-intake material awaiting owner disposition.
- **Owner direction** — binding input to the successor-decision process; not yet canonical.
- **Recommendation** — proposed resolution.
