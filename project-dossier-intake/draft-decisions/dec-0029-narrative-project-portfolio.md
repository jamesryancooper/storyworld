## Context

The catalog consolidates the full narrative portfolio: eight original properties, four promoted properties (the Ryan and Nicol fairytale, the Saint Michael artwork series, SciSpark curriculum storylines, the Ambience channel), one prospective project (metaphysical), one unnamed candidate (visual advice-storytelling), and ten generated showcase concepts — 26 projects in nine type groups, each on a fixed field template with "To be defined" marking open owner decisions. It also assigns every platform pattern (fourteen post-F1 pattern fixtures, eight schema probes) a designated showcase property.

## Decision (proposed)

1. Adopt the catalog as the governing narrative-portfolio inventory and register it as a supporting dossier artifact; amend canonical chapter 01's concept map per the impact map.
2. Adopt its status conventions (Established / Active / In development / Planned / Candidate / Prospective / Concept) and the "(working title)" marker.
3. Adopt the pattern-showcase coverage policy: every accepted platform pattern carries one designated showcase property; the catalog's coverage tables are authoritative for that mapping.
4. Confirm the ten generated concepts as concepts (retained as showcase designations; production requires separate authorization), and the candidate advice property as pending adoption and naming.
