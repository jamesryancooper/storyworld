# Adapter Interface Contracts

Normative exchange contracts for the three adapter families (Appendix B:
"Commerce Foundry and runtime adapter interfaces"; channel adapters per part
04 section 13). Strict JSON, validated for parseability and required keys by
`../tests/validate_contracts.py`. Payload shapes are owned by the contract
schemas (tag: URIs); these documents own operations, direction, idempotency,
and boundary rules. No interface grants authority (charter authority-matrix).
